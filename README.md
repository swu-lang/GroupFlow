# GroupFlow

**Project Title:** Designing and Implementing a Course-Project Coordination Platform for Student Group Work

## Team Members
- Shuang Wu — GitHub: @swu-lang
- Weiye Liu — GitHub: @redbudthu

## Project Description

GroupFlow is a proposed lightweight web application focused on helping university students coordinate group assignments and manage academic tasks.

This project explores challenges in student group collaboration, including unclear responsibilities, scattered project information, and difficulties tracking progress. The project direction will be refined based on user research and the design thinking process.

## Current Phase

**Phase 1: Background Research & Design Thinking Planning**

This phase focuses on understanding student needs, reviewing existing collaboration tools, identifying stakeholders, and planning future design and technical work.

No implementation or usability testing has been completed at this stage.
